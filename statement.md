# Project Statement: Scientific Calculator

## Problem Statement

People often need to perform everyday arithmetic and basic scientific calculations. Doing these calculations manually can take time and may lead to mistakes. This project provides a simple, menu-driven calculator that performs common operations and shows their results in the terminal.

## Scope of the Project

The project is a command-line application written in Python. It supports basic arithmetic, powers, real square roots, trigonometric calculations using angles in degrees, base-10 and natural logarithms, mean and median, and square roots of complex numbers.

The calculator accepts user input through the terminal, checks for invalid numeric input, prevents division by zero, and reports results or relevant error messages. It uses Python's built-in `math`, `cmath`, and `statistics` modules. It does not include a graphical interface, persistent calculation history, or advanced symbolic mathematics.

## Target Users

- Students learning or practicing basic mathematics and scientific calculations
- Beginners learning Python functions, conditionals, loops, input handling, and standard-library modules
- Anyone who wants a small terminal-based calculator for supported operations

## High-Level Features

- Menu-based interface with an option to exit
- Addition, subtraction, multiplication, and division
- Exponentiation and real square roots
- Sine, cosine, and tangent for angles entered in degrees
- Logarithms with base 10 or base *e*
- Mean and median for comma-separated values
- Complex number square roots
- Basic handling of invalid input, division by zero, negative real square roots, and oversized results
